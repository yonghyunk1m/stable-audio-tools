# ICME 2026 NTU ATTM Grand Challenge — Execution Plan

> Last updated: 2026-03-19
> Challenge: Text-to-Music Generation (500M core model limit)

---

## 1. Challenge Rules

### Model limit
- **Core generative model <= 500M parameters**
- Core = main generation architecture (DiT, conditioners)
- **Auxiliary (excluded)**: VAE, text encoder, vocoder

### Our model breakdown

| Component | Params | Classification |
|-----------|--------|---------------|
| DiT Core (16-depth, 1024-embed) | 339.1M | Core |
| NumberConditioner (seconds_total) | 0.2M | Core |
| Score conditioners | ~1M | Core |
| **Core total** | **~340M** | **68% of 500M limit** |
| VAE (Oobleck enc+dec) | 156M | Auxiliary |
| T5-base | ~109M | Auxiliary |

### Evaluation metrics
1. **FAD** — audio quality (lower = better)
2. **CLAP Score** — text-audio alignment (higher = better)
3. **CCS (K/M)** — concept coverage per prompt (higher = better)

### Test format
- 100 prompts, <100 words each, caption-like style
- Generated by Qwen2-Audio-7B from musical tags
- Audio >= 10s, first 10s evaluated

---

## 2. Data Pipeline

### MTG-Jamendo (primary dataset)
1. [x] 55K tracks, full-length audio (508GB)
2. [IN PROGRESS] Vocal separation via Mel-Band Roformer (GPU 0-3, ~2-3 days)
3. [x] Qwen2-Audio tag→caption: 54,753 generated (ICME test style)
4. [x] ICME reference captions downloaded (55,701, Qwen + MusicFlamingo)
5. [ ] Score with `ablation_dropout_100.pt` (audio-only reward model)

### Caption strategy
- **Train with mixed captions** for robustness:
  - ICME reference captions (long, detailed, audio-based)
  - Our Qwen tag→caption (short, ICME test style)
- This covers both training diversity and test-time alignment

## 3. Training Plan

### Experiments

| Exp | Data | Score | Purpose |
|-----|------|-------|---------|
| (i) | Jamendo instrumental | w/ score | ICME submission |
| (ii) | FMA | none | Baseline |
| (iii) | FMA | w/ score | Score conditioning ablation |

All three train from scratch (random init).

### Score conditioning design
- Fourier score embedding + cross-attention (best performing approach)
- Separate score projection (`to_score_embed`) to avoid text degradation
- Score dropout 30% for CFG amplification
- Audio-only reward model (`ablation_dropout_100.pt`) for scoring

---

## 4. Inference Optimization

- `continuous_score = max` for FAD optimization
- CFG grid search: text_cfg x score_cfg
- `seconds_total = 10` (matches evaluation)
- Steps: 50-100

---

## 5. Risks

| Risk | Mitigation |
|------|-----------|
| Score conditioning doesn't improve FAD | Fall back to data filtering (top 30% only) |
| Caption mismatch with test prompts | Multiple caption styles during training |
| 160M headroom unused | Can increase DiT depth or add adapters if needed |
